## 三、压测暴露并修复的引擎 bug

**CUDA graph 私有池未计入 KV 预算**（`7dae741`）：
600 块 KV + 11 档图共享 pool + 捕获期激活把 32GB 卡吃满，eager
prefill 分配 20MB 即 OOM → `fail_all_inflight` 全批判死（实测 384
aborts / 24 step errors）。修复：`envs.CUDAGRAPH` 开启时激活 headroom
512MB → 1GB；修复后 KV 池自动降到 335 块，零错误。

**load_test.py token 计数失真**（`2312f1a`，评审 #7）：按空格分词对
中文/代码输出失真数倍（曾导致 tokens/s 断崖、TPOT=0）。改为非流式读
`usage.completion_tokens`、流式按含 content 的 chunk 计。

## 四、容量结论（32GB 卡）

- 335 块 KV ≈ 21k token 位置，叠加 29.26GB 模型权重后余量极紧
- 32 并发 / 762.9 tok/s 是该硬件上限；更高并发需 48GB+ 卡
- 48GB 卡：KV 池可翻数倍，并发与长上下文余量显著改善
