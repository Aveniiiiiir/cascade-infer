### 实际守护方式

该实例 PID 1 为 bash，由 `/bin/supervisord` 托管，**没有可用的 systemd**；
实际部署使用独立 supervisord 实例（`/etc/cascade-infer/supervisord.conf`），
同时守护 `cascade-infer` 与 `cascade-nginx`；systemd unit 仅提供给标准 Linux 主机。

## 4. 灰度状态

- 默认配置：`bf16`、`CASCADE_NGRAM_DRAFT=0`、`CASCADE_KV_DTYPE=bf16`。
- n-gram / FP8 已在真实 V2-Lite 上各自通过 e2e；不作为默认流量配置。
- 服务仅监听 `127.0.0.1:8000`，业务通过 nginx `8080` 访问。
- API key 只在实例 `/etc/cascade-infer/env`（root-only）中，不写入仓库/公开文档。
- 告警规则依赖 Prometheus；本实例未部署完整 Prometheus/Alertmanager 栈，
  规则文件与抓取示例已就绪，接入监控系统后生效。

## 5. 放量与回滚

- 观察 5xx/判死率、TTFT/TPOT、tokens/s、GPU 显存、进程重启。
- 错误率 >2% 持续 5 分钟：禁止放量；实例不可用 >5 分钟：回滚。
- GPU 显存 >95% 持续 5 分钟：降低 `MAX_SEQS` 或回滚。
- 回滚使用上一 release tree 与 env 文件；保留 nginx 配置不变。

## 6. 前端对话入口

- 静态站部署到实例 `/opt/cascade-web`，nginx 8080 直接提供：
  - `/`：官网落地页
  - `/chat.html`：对话页
- 对话页同源调用 `/ui-api/v1/chat/completions`；nginx 仅允许 `127.0.0.1`
  并把 API key 从 root-only 的 `/etc/cascade-infer/ui_auth.conf` 注入，
  浏览器端不保存、不输入密钥。
- Windows 双击项目根目录 `打开Cascade对话.bat`：建立免密 SSH 隧道
  `18080 → 实例 8080` 并打开 `http://127.0.0.1:18080/chat.html`。
  已为当前 Windows 用户安装 SSH public key，无需输入密码。
- `/v1/*` 保持客户端自带 Bearer key；生产门禁仍验证无 key 返回 401。

## 7. 已知限制

- 单卡 32GB 仅适合灰度；正式业务建议 48GB。
- FP8 KV 只省 KV，不减少 29.3GB 模型权重。
- 仅支持 DeepSeek-V2/V2-Lite；不支持 V3/R1。
- 公网 HTTPS/WAF/审计未包含在内，当前为内网灰度配置。
