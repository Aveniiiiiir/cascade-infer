01最新一轮交付

1. n-gram / prompt-lookup 无 draft 投机解码

  • 新增 cascade/sampling/ngram_draft.py：基于序列历史的最长后缀匹配 （bytes.rfind，C 速度），无状态实现，不依赖 draft 模型。
  • sampling/mtp_verify.py 新增稀疏草案路径： one-hot 草案不分配 [K, V] logprobs；接受概率用单点分布的精确 min(q[d], p_d)，拒绝残差只在草案列做 relu(q − α·p_d·e_d)。
  • 复用既有 MTP 的验证 / 乐观推进回滚 / SO 掩码 / 确定性随机流； 贪心下与非投机输出逐 token 一致。
  • 开关：CASCADE_NGRAM_DRAFT=1（可调 CASCADE_NGRAM_MIN_GRAM / MAX_GRAM / MAX_DRAFT）。

2. CUDA Graph 多 token 验证行

  • CudaGraphRunner 增加 tokens_per_seq = 1+K：档位按 seq 数分档， 张量按 seq × v 行捕获，回放按每 seq 行列表写入。
  • MLA 吸收路径新增 uniform_v 分支：全段等长时 q 块元数据全部由 device 张量构造（positions[::v] + v 推导段首位置），捕获区间零 .item() 同步；varlen / 动态长度自动退化 eager。
  • padding seq 的 block 表每次回放重置为 scratch，杜绝批收缩时垃圾 latent 串写活跃序列。

3. FP8 KV Cache（DeepSeek-V3 生产同构）

布局latent c 存 float8(e4m3)，k_rope 保持 bf16， 每 128 维一组 fp32 scale。
体积656 B/token/层，bf16 为 1152 B，约 1.76× 压缩。
实现量化在 PyTorch 侧完成（图捕获安全），Triton kernel 只搬字节；decode / prefill kernel 内 dequant 后复用同一组 tl.dot。
开关--kv-cache-dtype fp8 或 CASCADE_KV_DTYPE=fp8。
