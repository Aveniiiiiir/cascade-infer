# 修复与亮点总览（截至 2026-11-26）

本文件汇总项目从审计到量产验收的关键 bug 修复与工程亮点，作为
`docs/` 历史报告的索引与最新一轮（n-gram / FP8 KV / 官网落地页）的归档。

## 一、最新一轮交付（2026-11-24 ~ 11-26）

### 1. n-gram / prompt-lookup 无 draft 投机解码

- 新增 `cascade/sampling/ngram_draft.py`：序列历史最长后缀匹配
  （`bytes.rfind`，C 速度），无状态，不依赖 draft 模型。
- `sampling/mtp_verify.py` 新增**稀疏草案**路径（`draft_token_probs`）：
  one-hot 草案不分配 `[K, V]` logprobs；接受概率用单点分布的精确
  `min(q[d], p_d)`，拒绝残差只在草案列做 `relu(q − α·p_d·e_d)`。
- 复用既有 MTP 的验证 / 乐观推进回滚 / SO 掩码 / 确定性随机流，
  贪心下与非投机输出逐 token 一致。
- 开关：`CASCADE_NGRAM_DRAFT=1`（可选 `CASCADE_NGRAM_MIN_GRAM` /
  `MAX_GRAM` / `MAX_DRAFT`）。

### 2. CUDA Graph 多 token 验证行（投机解码上图的必要条件）

- `CudaGraphRunner` 增加 `tokens_per_seq = 1+K`，档位按 seq 数分档、
  张量按 `seq×v` 行捕获；回放按每 seq 行列表写入。
- MLA 吸收路径新增 `uniform_v` 分支：全段等长时 q 块元数据全部由
  device 张量构造（`positions[::v] + v` 推导段首位置），捕获区间零
  `.item()` 同步；varlen / 动态长度自动退化 eager。
- padding seq 的 block 表每次回放重置为 scratch，杜绝批收缩时垃圾
  latent 串写活跃序列（历史高危问题的延续防护）。

### 3. FP8 KV Cache（DeepSeek-V3 生产同构）

- 布局：latent `c` 存 `float8_e4m3`，`k_rope` 保持 bf16，每 **128 维**
  一组 fp32 scale；V2-Lite 656 B/token/层（bf16 为 1152 B，≈1.76×）。
- 量化在 PyTorch 侧完成（图捕获安全），Triton kernel 只做字节搬运；
  decode / prefill FP8 kernel 在 kernel 内 dequant 后复用同一组 tl.dot。
- 显式路径 gather 使用 int8 视图（CPU 不支持 fp8 高级索引）。
- 开关：`--kv-cache-dtype fp8` 或 `CASCADE_KV_DTYPE=fp8`。

#### 精度迭代（真实模型 teacher-forcing）

| 版本 | explicit 一致率 | 结论 |
|---|---|---|
| per-token 单 scale | 627/640 = **0.9797** | 低于 0.985 门槛，放弃 |
| 每 128 维分组 scale | e2e **PASS**（`FP8B_EXIT=0`） | 采用（V3 生产格式） |

### 4. 本轮捕获并修复的问题

| 问题 | 根因 | 修复 |
|---|---|---|
| FP8 KV 精度不达门槛 | 单 token 一个 absmax scale，outlier 通道误差大 | 改为每 128 维一组 scale |
| CUDA Graph 遇 MTP/n-gram 直接退化 eager | 图只支持每 seq 1 行 | `tokens_per_seq=1+K` + `uniform_v` 图安全路径 |
| n-gram 未命中 token 被当作真实草案 | 输入侧 0 填充 vs 验证侧 -1 哨兵语义不一致 | 输入侧负值映射 0，验证侧 -1 强拒 |
| n-gram `max_draft < 引擎 K` 时草案整体丢弃 | 返回长度不足 K，验证判为无草案 | 尾部补 -1 哨兵到 K |
| FP8 显式路径 CPU 测试崩溃 | `index_cpu not implemented for Float8_e4m3fn` | int8 视图 gather 后转回 fp8 |
| `uniform_v` 在 ref 路径断言失败 | 参考实现只接受显式 segments | ref 路径由 `seqlens-v` 还原 segments |
| `serve.sh` 在非交互 SSH 下启动失败 | PATH 无 `python` | 按 `PYTHON` → `python` → conda → `python3` 解析 |
