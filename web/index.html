CAPABILITIES

一整套 生产级底座

连续批处理 + Chunked Prefill

decode 与 prefill 混合 varlen 批同步推进，前缀缓存 block 哈希链 + LRU + COW。

分页 KV + 前缀复用

block 表跨层共享，block id 0 保留；抢占重算命中缓存，长会话零重复计算。

MTP + n-gram 投机解码

采样式拒绝采样保证输出无损；n-gram 无需 draft 模型，复用验证/回滚管线。

FP8 KV Cache

结构化输出

xgrammar 的 regex / JSON schema / EBNF，异步编译 + 失败隔离，不阻塞调度热路径。

OpenAI 兼容服务

ARCHITECTURE

同步序引擎，
每一步都可解释

调度、组批、前向、采样、提交在一帧内闭环。CUDA Graph 只捕获 forward_hidden，lm_head 留在图外；padding 行恒指 scratch 块， 批收缩也不会污染活跃序列。

  • 01

    Scheduler

    FCFS prefill + LCFS decode，抢占重算与 NEVER 路径防活锁。

  • 02

    BlockManager / PrefixCache

    block id 1..N，容量守卫恒用 capacity（扣除 reserved）。

  • 03

    ModelRunner

    MLA 吸收路径 + fused MoE + 分页注意力 Triton kernel。

  • 04

    Engine Loop

    失败隔离与回执：异常步只判死本批，引擎继续服务。

QUICKSTART

三行命令，跑起来

# 安装 + 启动（模型加载 7-10 分钟）
pip install -e ".[dev,so]"

CASCADE_MODEL=/models/DeepSeek-V2-Lite \
  API_KEY=sk-cascade \
  bash scripts/serve.sh

# 就绪后直接走 OpenAI 接口
curl http://localhost:8000/v1/completions \
  -H "Authorization: Bearer sk-cascade" \
  -d '{"model":"cascade","prompt":"你好","max_tokens":64}'
from cascade.entrypoints.llm import LLM

llm = LLM("/models/DeepSeek-V2-Lite", max_model_len=4096)
print(llm.generate(["用三句话解释 MLA 注意力"], max_tokens=128)[0])
# FP8 KV：c 走 e4m3，rope 保持 bf16，每 128 维一组 scale
CASCADE_KV_DTYPE=fp8 \
  CASCADE_MODEL=/models/DeepSeek-V2-Lite \
  bash scripts/serve.sh

# 无 draft 模型的 n-gram 投机解码
CASCADE_NGRAM_DRAFT=1 bash scripts/serve.sh
